# Orbital

A real-time 3D satellite tracker built with vanilla JavaScript and Three.js.

## Current status

- Phase 1: 3D Earth scene with day texture, Milky Way starfield, and orbit camera controls

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173

## Tech stack

- Three.js (WebGL)
- Vite
- satellite.js (coming in Phase 2)

Earth textures from [Solar System Scope](https://www.solarsystemscope.com/textures/) (CC BY 4.0).
